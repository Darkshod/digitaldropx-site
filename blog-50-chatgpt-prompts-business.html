50 ChatGPT Prompts for Small Business Owners

September 1, 2026 • 15 min read

Small business owners wear many hats. Here are 50 ChatGPT prompts to help you handle marketing, sales, operations, and customer service.

Marketing Prompts (1-10)

1. Business Description
Write a compelling business description for [BUSINESS]. Include what we do, who we serve, and why we're different. Under 150 words.
2. Social Media Bio
Write a social media bio for [PLATFORM] for [BUSINESS]. Under 160 characters. Include keywords and a CTA.
3. Google Business Description
Write a Google Business description for [BUSINESS]. 750 characters max. Include services, location, and keywords.
4. Tagline Generator
Generate 10 taglines for [BUSINESS]. Short, memorable, communicate value.
5. Ad Copy
Write 3 variations of Facebook ad copy for [PRODUCT]. Include headline, primary text, and CTA.

Sales Prompts (11-20)

11. Elevator Pitch
Write a 30-second elevator pitch for [BUSINESS]. Problem, solution, benefit.
12. Sales Email
Write a cold outreach email to [TARGET]. 3 sentences max. Problem, solution, CTA.
13. Proposal Template
Write a project proposal for [SERVICE]. Include scope, timeline, pricing, and next steps.
14. Follow-up Email
Write a follow-up email after a sales call. Reference key points, address concerns, propose next step.
15. Objection Handler
Respond to this sales objection: "[OBJECTION]". Be empathetic, provide evidence, suggest alternative.

Operations Prompts (21-30)

21. SOP Creator
Write an SOP for [PROCESS]. Include steps, tools needed, tips, and common mistakes.
22. Meeting Agenda
Create a meeting agenda for [TOPIC]. 30 minutes. Include discussion items, time allocation, and outcomes.
23. Project Plan
Create a project plan for [PROJECT]. Include phases, tasks, timeline, and dependencies.
24. Job Description
Write a job description for [ROLE]. Include responsibilities, requirements, and benefits.
25. Process Improvement
Analyze this process: [PROCESS]. Suggest 3 improvements to save time or reduce errors.

Customer Service Prompts (31-40)

31. FAQ Generator
Generate 10 FAQ questions and answers for [BUSINESS]. Cover pricing, process, and policies.
32. Complaint Response
Respond to this customer complaint: "[COMPLAINT]". Apologize, explain, offer solution.
33. Thank You Email
Write a thank you email after purchase. Include next steps, support contact, and review request.
34. Refund Policy
Write a clear refund policy for [BUSINESS]. Fair, professional, easy to understand.
35. Live Chat Script
Write live chat scripts for: greeting, common questions, escalation, closing.

Content Prompts (41-50)

41. Blog Post Outline
Create a blog post outline for "[TITLE]". 10 sections with key points for each.
42. Email Newsletter
Write a weekly newsletter about [TOPIC]. Subject line, value content, CTA.
43. Video Script
Write a 2-minute video script for [TOPIC]. Hook, content, CTA.
44. Case Study
Write a case study for [CLIENT]. Problem, solution, results, testimonial.
45. Product Description
Write a product description for [PRODUCT]. Headline, benefits, features, CTA.
